# 研读舱前端

> 公开源码范围：本文保留原开发环境的实施与验证历史。提到的日志、截图、仓库外 QA/研究原始材料不在此公开目录；当前可用测试和质量限制见 [EVIDENCE 摘要](../EVIDENCE.md)。


独立的 Vue 3 + TypeScript + Vite 中文资料研读界面。资料选择、异步任务和原文依据有清晰的三个阅读层次。

## 运行与构建

需要 Node.js 22.12+（本次使用 24.15.0）。在本目录执行：

```powershell
npm install --cache .npm-cache --registry https://registry.npmjs.org
npm test
npm run dev
npm run build
```

开发地址 `http://127.0.0.1:5174`，代理 `/api` 至 `127.0.0.1:8099`。构建写入 `../server/static`；启动后端后同源 UI 地址为 `http://127.0.0.1:8099/`。所有写请求（含上传）携带 `X-Requested-With: SourcePilot`。

## 使用

- 左侧上传 PDF、Markdown、TXT、PNG/JPEG，可多选或拖放；显示资料版本、页数、解析状态与失败原因。
- 勾选资料限定任务与检索范围；不勾选时使用全部可用资料。点击资料名称直接打开该版本第一页。
- 检索支持混合、语义、词语模式；显示后端本次实际模式及是否完成重排，不将回退结果标成语义检索。
- 输入问题创建异步任务，自动刷新真实步骤、状态与答案。运行中可取消；失败、中断、取消或达到本轮限额时可继续。
- 左侧历史可重开任务，当前任务链接为 `/?run=...`；完成后下载 Markdown 报告。
- 搜索结果与答案引用均打开明确文档版本及页码的原文面板；显示引用片段和完整原文，受控图片可一起查看。
- 小屏使用抽屉式资料列表和全屏原文阅读；键盘可见焦点，`Esc` 关闭原文与侧栏。

## 设计记录（两轮）

第一轮：研读桌布局。资料架藏青 `#242d44`，阅读背景 `#f8f9fc`，纸面白 `#ffffff`，正文 `#303547`，操作紫 `#6552b5`，分隔线 `#e6e7ef`。系统 Microsoft YaHei UI / PingFang SC 负责正文和控件；欢迎页使用楷体回落栈强调阅读气质，实际任务文本仍以清晰为主。

```text
┌───────────┬──────────────────────┬──────────┐
│ 资料库    │ 任务标题 / 检索问题   │ 原文阅读 │
│ 上传      │                      │ 固定版本 │
│           │ 研读过程             │ 页码     │
│ 研读记录  │ 结论                 │ 引用片段 │
│           │ 原文依据             │ 完整原文 │
└───────────┴──────────────────────┴──────────┘
```

第二轮复核：资料任务以阅读流呈现，去掉通用仪表盘的等大卡片、大数字和营销口号；资料侧栏保持低亮度，当前问题与原文是主角。只在有真实运行步骤时显示步骤计数。模型未就绪明确提示，无模拟回答或装饰图表。

## 测试证据

2026-10-15，先写测试与空实现，完整运行得到 **4 失败 / 0 通过**。断言定位文档 ID 编码、版本页码、危险图片 URL、任务状态和本机请求标记。实现后 **4 通过 / 0 失败**。

后端确认图片使用 `/api/assets/<sha256>.png`、可续跑状态增加 `budget_exceeded`，先增加断言再次得到 **2 失败 / 2 通过**，补充实现后恢复 **4 通过 / 0 失败**。实屏发现模型连接探测可能拖住初始资料加载，增加“模型探测未返回时资料与历史仍可打开”测试，先见 **1 失败 / 4 通过**，分离探测后完整运行 **5 通过 / 0 失败**。`npm run build` 包含 TypeScript 检查且通过。

已用真实 Chrome 打开开发地址检查工作台截图，能显示后端的实际资料与历史记录；复核后加深辅助文字、阅读元信息及资料架小字对比度。上传/模型任务/引用/下载的独立端到端证据由根验收记录负责。源码经过项目局部 Prettier 格式化，格式化后重新运行完整测试与构建。

独立移动端检查使用 390×844 Chrome viewport：收起后侧栏坐标 `left=-280, right=0`、无横向溢出；菜单展开后 `left=0, right=280` 且遮罩可见；选择“检索资料”后再次完全收起，遮罩消失，检索页无遮挡。已检查展开和关闭截图，并恢复默认 viewport。截图应等侧栏过渡结束，避免把 resize 过程当作最终布局。

前端不生成模型答案，不将图片未解析标成 OCR 成功。模型配置、文档解析、真实工具循环和持久化检查点由后端实现并独立验证。答案按纯文本安全渲染，不执行其 HTML；报告使用受控下载接口。
