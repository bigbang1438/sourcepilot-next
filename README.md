# 研读舱 · SourcePilot Next

Python / RAG / Agent 个人作品：把个人手册、文章和截图放进同一资料库，限定资料范围提出问题，查看检索、读页和按需看图的过程，回看对应版本的原文，再下载带来源的 Markdown 草稿。

主要针对两类实际开发失败进行修订：模型已读到相关页，却因长引用字段抄写错误而无法完成；任务取消、预算和报告提交的状态不一致。短页面/证据标识由服务器回填版本、页码和原文，任务使用累计活动时间预算、真实 worker 状态和条件事务提交。引用合法仍不代表结论正确。

这是**单机个人资料库**，没有客户落地或用户工时收益。默认没有多用户隔离、网页搜索、自动备份和公网服务。界面和报告明确标为“结论草稿 / 尚未人工复核”，需要使用者核对原文。

## 运行前需要准备什么

- Python 3.12 与 `uv`；后端依赖按 `server/uv.lock` 安装。
- Ollama 兼容的本机模型服务，支持 `/api/tags`、`/api/chat` 和 `/api/embed`；聊天模型须能按约束生成工具决策 JSON。图片、扫描页和图表还需要可用的视觉模型。
- Node.js 24 仅在重新构建/测试前端时需要。仓库已包含当前 `server/static` 页面。
- 仓库不附带模型权重、原资料库或测试 PDF，需要自行准备。

### 模型名称和地址必须对应你实际安装的模型

本机验收使用的配置如下，保留名称是为了交代验证条件，**不是公共下载清单**：

| 用途 | 验收地址 | 验收模型名称 |
| --- | --- | --- |
| 聊天决策 | `http://127.0.0.1:11435` | `portfolio-qwen3-4b-instruct:latest` |
| 嵌入 | 同上 | `portfolio-bge-m3:latest` |
| 视觉 | `http://127.0.0.1:11436` | `qwen3-vl:2b` |

`portfolio-*` 是原验收环境的本机别名，不是可以直接 `ollama pull` 的公共模型名。请先启动你自己的本机模型服务，确认已安装模型列表，并用环境变量替换为实际名称。代码不接受远程模型地址。你可以让文字与视觉指向同一兼容服务，也可以像验收环境那样分别运行；可用性和硬件资源需自行验证。

例如在 PowerShell 中设置下面这些变量，值应由你自己的已安装模型填写，而不是原样执行占位值：

```powershell
$env:SOURCEPILOT_OLLAMA_URL='http://127.0.0.1:11434'
$env:SOURCEPILOT_CHAT_MODEL='填写已安装的聊天模型名称'
$env:SOURCEPILOT_EMBEDDING_MODEL='填写已安装的嵌入模型名称'
$env:SOURCEPILOT_VISION_URL='http://127.0.0.1:11434'
$env:SOURCEPILOT_VISION_MODEL='填写已安装的视觉模型名称'
cd server
uv sync --frozen
uv run python -m sourcepilot
```

打开 `http://127.0.0.1:8099/`。模型不存在或调用失败会明确报错，不回填演示答案；嵌入不可用时检索可标明退回 BM25，视觉不可用则不应把图片/扫描件伪装成已解析。

重新构建前端：在 `web` 目录运行 `npm ci`、`npm test`、`npm run build`，产物写入 `server/static`。后端测试在 `server` 目录运行 `uv run pytest`。不要同时启动两个后端进程操作同一资料目录。

## 如何使用

1. 上传自己的 UTF-8 TXT/Markdown、未加密 PDF 或 PNG/JPEG。单文件最多 20 MB，PDF 最多 60 页；图片和扫描件需要视觉服务。
2. 勾选本次需要的资料，写明对象、版本和条件。未勾选时会使用全部可用资料。
3. 点击开始研读，观察实际检索/读页/看图步骤。停止请求不等于执行已经释放，需等 worker 退出后再续跑。
4. 打开关联引用，逐项核查原文中的数字、单位、条件和结论。视觉转录会标明来源类型，应回看原图。
5. 下载 Markdown 草稿，保留人工复核。新任务固定资料版本，同名新上传不会改写既有任务来源。

## 已经验证什么，仍会错在哪里

本地后端 39 项回归、前端 7 项测试通过；最终报告提示修改后又复跑相关后端 8 项，后者是子集，不是新增全套。受控测试证明协议和部分边界，不证明模型准确率。

真实官方资料任务分开人工判分：原 6 题为 **3 correct / 2 partial / 1 incorrect**，独立新 4 题为 **3 correct / 1 partial**。全部生成报告不等于全答对；两批样本很小，不能合成通用准确率。错误包括把总电流误当每口电流、增加来源不支持的解释、没有真正看图却答图题。见 [EVIDENCE.md](EVIDENCE.md)。

短证据可能遗漏跨段条件，小模型可能误读、遗漏、受资料指令影响或作无依据推论。默认重排关闭，NumPy 为本机精确向量扫描，未验证大资料量性能；更换嵌入模型需重新导入。资料明文保存在本机，没有多用户权限、加密、自动备份、垃圾回收或生产负载保证。取消 worker 不保证模型服务端 GPU 立即停止，强制退出可能重放尚未提交的推理。

详见 [实施与修订记录](DEVELOPMENT_NOTES.md)、[后端证据说明](backend-evidence.md)、[最终一致性修复](server/REVIEW_REPAIRS_2026-10-17.md)。原开发工作区的 QA、研究报告、原始 PDF 和运行数据未附在公开仓库，缺失的外部链接已用仓库内 EVIDENCE 摘要替代；没有凭空补造原始证据。
